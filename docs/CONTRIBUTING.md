# Contributing to Capacity Connect

First off, thank you for considering contributing to Capacity Connect! This project aims to revolutionize digital capacity building for the India Meteorological Department (IMD) as part of SIH26075.

## 🚀 Quick Start

1. **Fork & Clone** the repository.
2. **Install Dependencies:** `npm install` (Use `--no-bin-links` if working on Android/Termux environments).
3. **Run Dev Server:** `npm run dev`.

## 🎨 Architecture & Style Guide

Before you submit a Pull Request, please familiarize yourself with our architecture:
- 📖 Read the [Architecture Blueprint](./ARCHITECTURE.md) to understand the Repository Pattern.
- 🎨 We strictly use **Tailwind v4** and our custom CSS variables defined in `globals.css` for theming (avoid hardcoding colors).
- 🧩 We utilize **Lucide React** for consistent iconography.

## 🤝 Pull Request Process

1. Create a descriptive branch name: `feat/trainer-dashboard` or `fix/enrollment-bug`.
2. Ensure you have tested your code locally across the three main breakpoints (360px, 768px, 1280px).
3. Open a PR against the `main` branch.
4. **Important:** Add a clear description of what your PR accomplishes, including screenshots if there are visual changes.
5. Code will be reviewed by the core team before merging.

*Let's build the future of IMD training together! 🌩️*
