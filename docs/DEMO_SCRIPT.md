# SIH Presentation Demo Script (5 Minutes)

This script outlines the click-by-click journey for demonstrating Capacity Connect during the SIH presentation.

## Demo Accounts
- **Admin:** `admin@capacityconnect.com` / `Password123!`
- **Learner:** `learner@capacityconnect.com` / `Password123!`

---

## Part 1: The Learner Experience (2.5 mins)

**Goal:** Show how easy it is for an employee to consume content and track progress.

1. **Login (0:00 - 0:15)**
   - Open the app.
   - Login as `learner@capacityconnect.com`.
   - *Talking point:* "We land on the Learner Dashboard, designed to be clean, distraction-free, and mobile-responsive."

2. **Dashboard & Progress (0:15 - 0:45)**
   - Point out the **Overall Progress Bar** (e.g., currently at 20%).
   - Highlight the **Active Questionnaire Alert**: "Quarterly Compliance Survey due in 2 days."
   - Click into the survey, click two radio buttons, and submit.
   - *Talking point:* "Questionnaires allow rapid, deadline-driven data collection across the organization."

3. **Consuming Content (0:45 - 1:30)**
   - Navigate to the **"Introduction to Capacity Building"** module.
   - Click on the first resource (a PDF or Video).
   - Click the **"Mark as Complete"** button.
   - Return to the module view to show the progress indicator update.

4. **Taking an Assessment (1:30 - 2:30)**
   - Click on the **"Module 1 Assessment"**.
   - Answer 3 multiple-choice questions.
   - Submit the assessment.
   - Show the immediate results screen (e.g., "Score: 66% - Passed!").
   - Navigate back to the Dashboard to show the Overall Progress Bar has increased.

---

## Part 2: The Admin Experience (2.5 mins)

**Goal:** Show how administrators manage content and view insights.

1. **Switch Accounts (2:30 - 2:45)**
   - Log out.
   - Log in as `admin@capacityconnect.com`.
   - *Talking point:* "The Admin portal provides bird's-eye visibility and content control."

2. **Analytics Dashboard (2:45 - 3:30)**
   - Land on the Admin Dashboard.
   - Show the **Overall Completion Rate** chart.
   - Show the **Recent Activity Feed** (point out the Learner's recent assessment completion).
   - *Talking point:* "Admins can instantly identify which modules are highly engaging and which assessments have low pass rates, allowing for data-driven curriculum improvements."

3. **Content Management (3:30 - 4:15)**
   - Navigate to the **Curriculum Builder**.
   - Click **"Add New Resource"** in Module 2.
   - Add a dummy YouTube link, title it "New Training Video", and hit Save.
   - Toggle the module from "Draft" to "Published".
   - *Talking point:* "Updating the curriculum is instant. No IT tickets required."

4. **Questionnaire Management (4:15 - 4:45)**
   - Navigate to **Questionnaires**.
   - Click "Create New".
   - Add a title, set a deadline for next Friday, and save.
   - *Talking point:* "Deploying a new compliance or feedback survey takes seconds."

5. **Conclusion (4:45 - 5:00)**
   - Return to Admin Dashboard.
   - Conclude: "Capacity Connect bridges the gap between organizational needs and individual growth, all in one seamless platform."
