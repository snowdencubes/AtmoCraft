# Resource Download Policy

DOWNLOAD ONLY IF ALL are true:
- redistribution_allowed = "yes"
- direct_file_url exists and is a PDF, EPUB, CSV, ZIP, or Image
- passes size limits (15 MB per file, 300 MB total)
- passes magic-bytes check

DO NOT DOWNLOAD:
- videos, websites, content behind logins
- items with redistribution_allowed = "no" or "unknown"
