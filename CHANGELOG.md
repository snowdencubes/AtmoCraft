# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.1.0] - 2026-09-30

### Added
- Complete initial prototype of the Capacity Connect portal.
- Role-based Dashboard experiences (Trainee, Trainer, Admin).
- In-memory mock database with `zustand/middleware` persist store.
- Local indexed file storage via `idb-keyval` for resources and certificates.
- Web Crypto API based authentication layer (demo).
- Command Palette interface (`Cmd+K`).
- Full UI component architecture using Tailwind CSS v4.
- Initial GitHub Actions CI pipeline and Issue/PR templates.
- Complete documentation including Architecture Blueprint and Data Schema.

### Planned
- Supabase migration for PostgreSQL database and robust authentication.
- Real-time notifications and chat features.
- Advanced administrative reporting algorithms.
